SQLD 정규화 정리

2026. 9. 15. 21:30 (수정 2026. 9. 16. 10:00) · SQL

[샘플 글] 정규화는 데이터의 중복을 줄이고 이상 현상(삽입·수정·삭제 이상)을 막기 위해 테이블을 나누는 과정이다. 이 문단은 여러 줄로 넘어가도 글자가 괘선 위에 놓이는지 확인하기 위한 긴 문장이다. 링크와 inline code, 밑줄, 취소선, 빨간 강조, 파란 강조, 연두 강조, 작은 글자, 큰 글자, 아주 큰 글자, 블러로 가린 글자도 함께 본다.

행간 넓게: 이 문단은 괘선 두 칸마다 한 줄씩 쓴다. 여러 줄로 넘어가는지 보려고 문장을 조금 길게 쓴다. 여러 줄로 넘어가는지 보려고 문장을 조금 길게 쓴다.

1. 정규형의 종류

대표적인 정규형은 다음과 같다.

  • 제1정규형: 모든 속성 값이 원자값
  • 제2정규형: 부분 함수 종속 제거
    • 기본키가 복합키일 때만 해당
  • 제3정규형: 이행 함수 종속 제거

1-1. 순서가 있는 목록

  1. 테이블을 분석한다.
  2. 함수 종속을 찾는다.
  3. 테이블을 분해한다.

참고 (h4 제목)

정규화가 항상 정답은 아니다. 조회 성능을 위해 일부러 반정규화를 하기도 한다.

2. 표

정규형제거 대상예시
1NF반복 그룹전화번호 여러 개를 한 칸에
2NF부분 종속(학번, 과목) → 학생 이름
3NF이행 종속학번 → 학과 → 학과장

3. 코드

SELECT d.dept_name, COUNT(*) AS cnt
FROM employee e
JOIN department d ON e.dept_id = d.dept_id
GROUP BY d.dept_name

HAVING COUNT(*) >= 3;
def normalize(rows):
    """중복 행을 제거한다."""
    return sorted(set(rows))
